# Simple Chat App 💬

এটি একটি অত্যন্ত সাধারণ চ্যাট অ্যাপ্লিকেশন যেখানে আপনি বন্ধুদের সাথে চ্যাট করতে পারেন।

## ফিচার

✨ **সহজ এবং সুন্দর ইন্টারফেস**
- নাম দিয়ে চ্যাট শুরু করুন
- রিয়েল-টাইম মেসেজিং
- মেসেজ সংরক্ষণ করা হয়
- অটোমেটিক উত্তর

## কিভাবে ব্যবহার করবেন

### ১. শুরু করুন
```bash
# ফাইল ডাউনলোড করুন বা ক্লোন করুন
git clone https://github.com/jamilislam1233/simple-chat-app.git
cd simple-chat-app
```

### ২. খুলুন
- শুধু `index.html` ফাইলটি ব্রাউজারে খুলুন
- অথবা একটি লোকাল সার্ভার চালান:
  ```bash
  python -m http.server 8000
  # তারপর http://localhost:8000 এ যান
  ```

### ৩. চ্যাট করুন
- আপনার নাম লিখুন
- "শুরু করুন" বাটনে ক্লিক করুন
- মেসেজ লিখে পাঠান
- অটোমেটিক উত্তর পাবেন

## ফাইল স্ট্রাকচার

```
simple-chat-app/
├── index.html      # মূল পেজ
├── style.css       # ডিজাইন
├── script.js       # কার্যকারিতা
└── README.md       # এই ফাইল
```

## ব্যবহারকৃত প্রযুক্তি

- **HTML** - পেজ স্ট্রাকচার
- **CSS** - সুন্দর ডিজাইন
- **JavaScript** - কার্যকারিতা
- **LocalStorage** - মেসেজ সংরক্ষণ

## ফিচার বর্ণনা

### চ্যাট ইন্টারফেস
- বাম পাশে অন্যের মেসেজ (ধূসর)
- ডানে আপনার মেসেজ (নীল)
- প্রতিটি মেসেজে সময় এবং নাম

### অটো রিপ্লাই
- আপনি মেসেজ পাঠালে অটোমেটিক উত্তর পাবেন
- বিভিন্ন মজাদার রেসপন্স

### মেসেজ সংরক্ষণ
- সব মেসেজ ব্রাউজারে সংরক্ষিত থাকে
- পেজ রিফ্রেশ করলেও মেসেজ থাকবে

## কাস্টমাইজেশন

### রঙ পরিবর্তন করুন
`style.css` ফাইলে এই লাইন পরিবর্তন করুন:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### অটো রিপ্লাই পরিবর্তন করুন
`script.js` এ `replies` অ্যারে পরিবর্তন করুন:
```javascript
const replies = [
    'আপনার উত্তর এখানে',
    'আরও একটি উত্তর',
];
```
